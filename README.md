# Summit Ridge Roofing — Website Redesign Demo

A conversion-focused website redesign concept for a fictional residential roofing contractor.

## Overview

Summit Ridge Roofing is a portfolio demo designed to demonstrate how an outdated local-service website can be transformed into a modern, mobile-first experience focused on generating calls and quote requests.

## Features

* Responsive mobile-first layout
* Conversion-focused hero section
* Clear calls to action
* Before/after website comparison
* Roofing services section
* Benefits and trust signals
* Service area presentation
* Customer testimonials
* FAQ accordion
* Quote/contact form with client-side validation
* Mobile navigation
* Scroll/reveal animations
* Basic accessibility considerations

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Inline SVG

No framework or backend is required.

## Demo Notice

This is a fictional portfolio project.

Company information, statistics, testimonials, contact details and other business data shown in the demo are illustrative and do not represent a real roofing company or real customers.

The contact form is also a frontend demonstration and does not submit information to a backend.

## Purpose

The project demonstrates:

* Local-service website redesign
* Conversion-oriented UX
* Responsive frontend development
* Clear information hierarchy
* Trust-building elements
* Lead-generation-focused landing page design
